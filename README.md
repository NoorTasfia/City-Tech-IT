# City Tech IT

City Tech IT is a modern IT studio and technology school website designed for showcasing digital services, portfolio projects, training courses, team members, pricing, testimonials, and contact information.

The platform presents City Tech as a Dhaka-based independent IT studio that builds websites, software, branding systems, hosting solutions, and practical IT training programs for students, freelancers, and small businesses.

## Features

- Modern responsive homepage
- Service showcase
- Portfolio / selected work section
- IT training course section
- Team profile section
- Pricing plans
- Testimonials
- Contact form and studio information
